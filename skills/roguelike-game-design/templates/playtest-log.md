## Observation prompts

- Before the first choice, can the player state the current goal?
- Can the player explain why a reward was chosen?
- Did the player try a different build or route?
- Did the player understand the failure cause?
- Did any UI state, color, sound, or touch target mislead the player?
- Did the player want to restart without being prompted?
