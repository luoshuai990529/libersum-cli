## Source roles

- `游戏设计艺术`: design worldview, lenses, iteration, player experience.
- `游戏设计深层设计思想与技巧`: challenge capability, emotion, journey variation, rewards, progression, and monetization as analysis lenses.
- `游戏机制：高级游戏设计`: state, feedback, economy, emergence, prototyping, balancing.
- `游戏设计深度剖析：Roguelike篇`: failure loop, variance, structure, pacing, persistence, fairness.
- `游戏数值百宝书`: numerical workflow, combat/economy models, review, visualization, and modularization.
- `Game Feel`: input, response, context, polish, metaphor, rules, metrics, and game-feel principles.
- `像素、复古、低成本 2D 游戏设计指南`: low-cost pixel production, reusable parts, animation, effects.
- `Visual Design Concepts for Mobile Games`: vision boards, visual hierarchy, character/prop design, multistate assets, global lighting, 2D pipeline, and art collaboration.
- `补充游戏 UI:UX`: mobile interaction, information hierarchy, accessibility, feedback, UI production.
- Mobile visual-design excerpt: chapter index only; not a source for detailed rules.
- Procedural-generation PDF: pending replacement or clean re-export.
