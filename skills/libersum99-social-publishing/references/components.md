# 自媒体组件选用

按内容选择，模板类和内联样式可以修改，不要求加载原设计系统的完整组件目录。

| 内容 | 小红书表达 | 公众号表达 |
| --- | --- | --- |
| 主标题 | 大字主题 + 红蓝关键词 + 留白 | 衬线标题 + 简洁间距 |
| 多个步骤 | 编号 + 标题 + 短说明，必要时拆页 | 按原文顺序编号分节 |
| 对比 | 两列或上下色块，字段对齐 | 窄屏逐项对照，保持标签与值 |
| 观点 | 大字结论 + 较小字号的适用范围 | 原文段落 + 少量高亮 |
| 引用 | 引文与来源同时呈现 | 浅奶色引用块 + 原有来源 |
| 代码 | 局部墨色代码面板，保留缩进 | 可换行等宽文本，检查长行 |
| 署名 | 正式头像 + 作者名 + 短签名 | 文末独立作者区 |

Chip Spider 适合标记技术主题；Circuit Divider 用于重要分节；Web Corner 限用于封面或结尾的一角。公众号中的 SVG 装饰若有必要，先转 PNG，否则用基础色条替代。

已有文字没有引用、金句、编号时，不为了套组件添加内容。纯装饰只改变视觉，不制造信息。
