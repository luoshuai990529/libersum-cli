# 品牌与视觉判断

LiberSum99 用手绘科技语言表达 AI、连接和探索。以红色卫衣人物、Chip Spider、手绘电路和蜘蛛网为识别符号。平台可调整底色和主强调色，但正文墨色、蜘蛛红与品牌图形保持一致。

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 清爽白 | #FFFFFF | 公众号清爽排版或小红书科技色调的主背景 |
| 暖奶白 / 深奶 | #FEFCF6 / #FAF6EB | 品牌暖色方案的背景、留白与浅色分区 |
| 蜘蛛红 | #E84A5F | 关键标题、人物和重点 |
| 科技蓝 | #2B7FD8 | 信息结构、电路与关键词 |
| 芯片黄 | #F4D758 | 小面积高亮和节点 |
| 墨色 | #1A1A2E | 正文和线稿 |

蜘蛛红和科技蓝用于层级，芯片黄只做小面积强调。按 [公众号](wechat.md) 或 [小红书](cards.md) 选用对应配色；单篇内容保持一套主色方案，不在每个章节或卡片间切换。颜色比例只作方向，不为了凑比例牺牲长文可读性。避免紫色霓虹、复杂 HUD、通用塑料 3D 和装饰压过内容。

作者名为 **LiberSum99**。文字签名为“向上攀登，持续探索新技术。”，只放在独立署名区，不拼成原文的一部分。

## 字体和布局

中文标题优先系统衬线（Songti SC、STSong、Noto Serif CJK SC），正文优先系统无衬线（PingFang SC、Microsoft YaHei、Noto Sans CJK SC），代码用系统等宽。模板不联网加载字体；更换电脑后字体可能不同，重新渲染并检查换行。需要固定字体时使用有授权的本地字体并随输出打包。

内容清晰度 → 品牌识别 → 装饰。固定颜色、字号层级、间距节奏和署名，同类段落用同一结构；封面、步骤、对比、代码和观点按内容改变版式。保留手绘温度，不故意歪斜文字，不强制图片溢出容器。

公众号是连续长文，小红书是固定尺寸静态画面；两者均不需要网页导航、hover、轮播、弹窗或入场动画。
